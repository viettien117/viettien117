<summary><b>In English</b></summary>

<br>

**RuBi — free tools for multiple-choice exams.** Four programs covering the whole
cycle: draw the answer sheet → mix the exam papers → grade with a photo → analyse
the results.

🌐 **[viettien117.github.io](https://viettien117.github.io)** — home page, with QR codes for every platform.

- **ExamScan** — snap a photo of the answer sheet and it is graded; no dedicated scanner needed.
  [App Store](https://apps.apple.com/app/id6782332992) ·
  [Google Play](https://play.google.com/store/apps/details?id=vn.examscan) ·
  [Windows](https://github.com/viettien117/ExamScan_Windows_updates/releases/latest) ·
  [macOS](https://github.com/viettien117/ExamScan_macOS_updates/releases/latest)
- **ExamSheet** — draws the answer sheet, with exactly the number of questions, options and test-code digits you need.
  [App Store](https://apps.apple.com/app/id6816303954) ·
  [Windows](https://github.com/viettien117/ExamSheet_Windows_updates/releases/latest) ·
  [macOS](https://github.com/viettien117/ExamSheet_macOS_updates/releases/latest)
- **ExamMixer** — generates several exam codes from a question bank written in Word, with an answer key ExamScan reads directly.
  [Windows](https://github.com/viettien117/ExamMixer_Windows_updates/releases/latest) ·
  [macOS](https://github.com/viettien117/ExamMixer_macOS_updates/releases/latest)
- **ExamInsight** — reads ExamScan's result file: average score, pass rate, score distribution, and which question the class got wrong most often.
  [App Store](https://apps.apple.com/app/id6816304403) ·
  [Windows](https://github.com/viettien117/ExamInsight_Windows_updates/releases/latest) ·
  [macOS](https://github.com/viettien117/ExamInsight_macOS_updates/releases/latest)

</details>
